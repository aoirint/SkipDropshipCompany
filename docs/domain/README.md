# Domain Knowledge

This directory contains implementation knowledge about Lethal Company and
reusable knowledge about dependencies. It does not define SkipDropshipCompany's product model or design decisions.

- [Dropship orders](dropship-orders.md) records the terminal and round
  lifecycle knowledge used to reason about pending purchases.
- [Dependency baseline](dependencies.md) explains NuGet minimum publish age,
  including automatic version selection, publication metadata, and restore limits.
